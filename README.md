## 만화 8컷 (작업 필요)

각 섹션마다 1컷씩 들어갈 자리에 `placeholder` 박스가 있다.
ChatGPT 4.x 또는 Codex로 다음 prompt를 사용해 PNG 받기:

| # | 위치 | Prompt 요약 |
|---|------|-------------|
| 01 | §1 MIT 도입 | 수학 공책에 펜 멈춘 학생, 챗봇이 답 대신 써주는 동안 뇌의 빛이 꺼져가는 일러스트 |
| 02 | §3 특성 1 | 베테랑이 AI 답에 빨간 펜으로 동그라미 치며 '맥락이 빠졌네' 표정 |
| 03 | §3 특성 2 | AI 마법 상자 뚜껑을 열고 통계적 단어 흐름을 들여다보는 사람 |
| 04 | §3 특성 3 | 학생이 머리 위 사고 지도에서 '여기 안다 / 여기 모른다' 표시 |
| 05 | §3 특성 4 | 프롬프트 카드를 다듬으며 'AI에게 내가 누구인지' 적는 장면 |
| 06 | §3 특성 5 | AI 답에 작은 빨간 점으로 '여기 살짝 틀렸어요' 표시되는 장면 |
| 07 | §3 특성 6 | 스마트폰 멀리, 종이책과 펜만 둔 학생 머리 위 따뜻한 빛 |
| 08 | §4 운전석 | 자율주행차 운전석에서 핸들 놓고 잠든 사람, 'AI 작동 중' 표시 |

상세 prompt는 `index.html` 안 placeholder의 `ph-prompt` 클래스에 명시.

스타일: **만화 8컷 일관성** — 따뜻한 톤, 한글 캡션 가능, 일러스트 스타일, 16:9 비율 권장.
